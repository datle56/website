Creating a USB Drive for Windows Installation

1. Determine Your System Architecture (32-bit or 64-bit)

  • Navigate to "Settings" > "System" > "About" in your Windows machine.
  • Under "System type," you will find the architecture of your system.

2. Acquire an Appropriate USB Drive

  • Ensure you have an 8GB or larger USB drive for reliable installation media.
  • Smaller drives may not accommodate the Windows installation files and associated data.

3. Format the USB Drive

  • Connect the USB drive to your computer.
  • Open "File Explorer" and right-click on the USB drive.
  • Select "Format..." from the context menu.
  • Choose either FAT32 or exFAT as the file system. (exFAT is recommended for drives larger than 32GB.)
  • Click "Start" to initiate the formatting process.

4. Download the Windows Installation Tool

  • Visit the official Microsoft website to download the Windows Installation Tool: https://www.microsoft.com/software-download/windows10
  • Select the appropriate tool based on your system architecture (32-bit or 64-bit).

5. Create the Bootable USB Drive

  • Run the Windows Installation Tool.
  • Agree to the license terms.
  • Select "Create installation media (USB flash drive, DVD, or ISO file)."
  • Choose your language, edition, and architecture (as determined in Step 1).
  • Select your USB drive as the destination for the installation media.
  • Click "Next" to begin the creation process.

Changing Boot Order

1. Restart Your Computer

  • Power down your computer completely.
  • Turn on the computer and wait for the initial boot screen to appear.

2. Enter BIOS Settings

  • Press the specified key (e.g., F2, Esc, or Del) displayed on the screen to enter BIOS settings. This key may vary depending on the computer manufacturer.

3. Adjust Boot Order

  • Navigate to the "Boot Order" section within the BIOS settings.
  • Use the arrow keys to move your USB drive (or "Removable Drives") to the top of the boot priority list.
  • Press F10 or the designated key to save and exit BIOS settings.

Installing Windows

1. Boot from the USB Drive

  • Restart your computer.
  • The computer should automatically boot from the USB drive. If not, continue to the next step.
  • When prompted, press any key to boot from the USB drive.

2. Language and Region Selection

  • Select your preferred language, time and currency format, and keyboard layout.
  • Click "Next" to proceed.

3. Product Key Entry (Optional)

  • If you have a valid Windows product key, enter it in the provided field.
  • If you do not have a product key, click "I don't have a product key" to continue with the installation process.

4. Custom Installation

  • On the "Which type of installation do you want?" screen, select "Custom: Install Windows only (advanced)."

5. Partition Selection

  • Select the partition where you want to install Windows.
  • You may create new partitions or delete existing ones using the options provided.

6. Installation Process

  • Click "Next" to initiate the Windows installation process.
  • The installation may take some time depending on the speed of your computer.

7. Windows Setup

  • Once the installation is complete, follow the on-screen prompts to set up Windows.
  • Create a user account, and adjust other settings as necessary.
