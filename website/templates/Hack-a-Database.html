Method 1: Using a SQL Injection

Step 1: Check for Vulnerability

  • Type the following syntax into a database login field: '''
  • If you receive an error message indicating invalid characters, such as: SQL injection error: Invalid character "'" found in SQL command. This suggests the database is vulnerable to SQL injection attacks.

Step 2: Determine the Number of Columns

  • Append the following to the login URL: order by 1
  • Increment the number in the order by clause until you encounter an error.
  • The number of columns in the database is one less than the number that triggers the error.

Step 3: Identify Query-Accepting Columns

  • Add the following to the URL: union select 1,2,3,4,5,6
  • The numbers that appear on the screen after running the query indicate which columns allow SQL queries.

Step 4: Inject SQL Statements

  • Replace the last part of the URL with: union select 1,concat(user()),3,4,5,6--
  • This will reveal the current authenticated user's username.

Method 2: Cracking the Database Root Password

Step 1: Attempt Default Passwords

  • Certain databases have no password set by default or use common default passwords. Try the following:
    • No password
    • "admin"
    • "root"
    • "password"
    • "12345"

Step 2: Use Common Passwords

  • Consult lists of commonly used passwords or employ password cracking tools.
  • Try various combinations of usernames and passwords, such as:
    • "admin" / "password"
    • "root" / "root"
    • "postgres" / "postgres"

Step 3: Utilize Password Auditing Tools

  • Employ tools like DBPwAudit or Access Passview.
  • These tools systematically attempt numerous passwords until the correct one is identified.

Method 3: Running Database Exploits

Step 1: Acquire an Exploit

  • Visit websites like Sectools.org for database exploits targeting specific database versions.

Step 2: Identify Vulnerable Networks

  • Use wardriving tools to locate open wireless networks that may host vulnerable databases.

Step 3: Connect to the Vulnerable Network

  • Establish a connection to the open network using your wireless device.

Step 4: Execute the Exploit

  • Run the database exploit to gain unauthorized access to the database.
