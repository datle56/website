Alter Your PC's Time and Date with a Simple Command Prompt Command

Part 1: Disabling Automatic Date and Time

Step 1: Access the Date and Time Settings

  • Open the Windows "Settings" menu by clicking on the gear icon in the Start menu or by pressing Windows Key + I.
  • Navigate to the "Time & Language" category.
  • Select the "Date & Time" tab.

Step 2: Disable Automatic Time and Date Synchronization

  • In the "Date & Time" settings, look for the "Set time automatically" option.
  • Click the toggle switch to turn it off.
  • This action will prevent your computer from automatically adjusting the date and time based on an external source.

Part 2: Changing the Date and Time

Method 1: Using the Command Prompt

Step 1: Launch Command Prompt with Administrator Privileges

  • Press Windows Key + R to open the "Run" command window.
  • Type "cmd" in the search field and press Ctrl + Shift + Enter to launch Command Prompt as an administrator.

Step 2: Change the Time

  • In the Command Prompt window, type the following command to change the time:
    • "time HH:MM:SS AM/PM" (e.g., "time 08:35:00 AM" for 8:35 AM)
  • Replace the placeholder values with the desired hour (HH), minute (MM), second (SS), and AM/PM designation.

Step 3: Change the Date

  • To change the date, first type the following command to display the correct date format for your location:
    • "date"
  • Once you have the correct format, type the following command to set the new date:
    • "date MM-DD-YYYY" (e.g., "09-25-2018" for September 25, 2018)
  • Replace the placeholder values with the desired month (MM), day (DD), and year (YYYY) numbers.

Step 4: Apply Changes

  • After entering the time and/or date commands, press Enter to apply the changes.
  • Close the Command Prompt window.

Method 2: Using the Date and Time Settings

  • Navigate to the "Date & Time" settings as described in Part 1.
  • Under "Change date and time," click on the date or time field you wish to modify.
  • Use the drop-down menus and calendar to select the desired values.
  • Click the "Change" button to apply the changes.

Conclusion:

With these simple steps, you can effortlessly disable automatic date and time updates or adjust them to your preference.
