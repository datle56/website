Graphing Linear Equations

Linear Equation Formula: y = mx + b * m: Slope (rate of change) of the line * b: Y-intercept (point where the line intersects the y-axis)

Steps to Graph a Linear Equation:

  1. Solve for y: Rearrange the equation into the form y = mx + b.
  2. Draw the Cartesian Coordinate Plane: Create two perpendicular axes labeled x and y.
  3. Locate the Y-Intercept (b): Plot the point (0, b) on the y-axis.
  4. Determine the Slope (m): Find the change in y (rise) over the change in x (run) from the point (0, b) or any other point on the line.
  5. Plot a Slope Coordinate: Using the slope, move up or down (rise) and right or left (run) from the y-intercept to plot a second coordinate.
  6. Connect the Coordinates: Draw a line through the y-intercept and the slope coordinate.

Graphing Single-Variable Inequalities

Steps to Graph a Single-Variable Inequality:

  1. Draw a Number Line: Create a horizontal line with arrowheads at both ends.
  2. Locate the Inequality Coordinate: Plot the point that satisfies the inequality on the number line. For example, for x < 1, plot the point 1.
  3. Draw the Open or Filled Circle: Place an open circle if the inequality is < or >, and a filled circle if the inequality is ≤ or ≥.
  4. Draw the Line: Extend the line from the circle to the left (for < or ≤) or to the right (for > or ≥).

Graphing Linear Inequalities

Steps to Graph a Linear Inequality:

  1. Find the Y-Intercept and Slope: Rewrite the inequality into the slope-intercept form (y = mx + b) and identify the y-intercept and slope.
  2. Graph the Inequality: Plot the y-intercept and create a dashed line if the inequality is < or >, or a solid line if the inequality is ≥ or ≤.
  3. Shade the Region: Shade the area above the line if the inequality is > or ≥, or below the line if the inequality is < or ≤.

Graphing Quadratic Equations

Quadratic Equation Formula: y = ax² + bx + c * a: Coefficient of the squared term * b: Coefficient of the x-term * c: Constant term

Steps to Graph a Quadratic Equation:

  1. Identify the Coefficients: Determine the values of a, b, and c.
  2. Find the Vertex: Calculate the x-coordinate of the vertex using the formula -b / 2a.
  3. Create a Coordinate Table: Plug in values for x around the vertex to create a table of coordinates.
  4. Plot and Connect the Coordinates: Plot the coordinates and connect them to form a parabola.

Graphing Quadratic Inequalities

Steps to Graph a Quadratic Inequality:

  1. Solve for the Coordinates: Use the quadratic formula to find the x-coordinates of the points where the parabola intersects the x-axis.
  2. Draw the Parabola: Plot the coordinates and connect them with a dashed or solid line, depending on the inequality sign.
  3. Shade the Region: Shade the area inside the parabola if the inequality is ≤ or ≥, or shade the area outside the parabola if the inequality is < or >.

Graphing Absolute Value Equations

Absolute Value Equation Formula: |x| = a * a: Constant value

Steps to Graph an Absolute Value Equation:

  1. Set the Absolute Value Equal to 0: Rewrite the equation as |x - h| = 0, where h is the value inside the absolute value signs.
  2. Find the Absolute Value Coordinate: Solve for x to find the coordinate where the absolute value is 0.
  3. Create a Coordinate Table: Create a table of coordinates by plugging in values for x around the absolute value coordinate.
  4. Solve for y-Coordinates: Calculate the y-coordinates using the absolute value function.
  5. Graph the Coordinates: Plot the coordinates to form a "V"-shaped graph with a vertex at the absolute value coordinate.
