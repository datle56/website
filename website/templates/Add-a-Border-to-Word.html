How to Insert Borders in Microsoft Word

Borders are a versatile way to add visual interest and organization to your Microsoft Word documents. You can use borders to frame pages, emphasize text, or create tables.

Page Border

For Windows:

  1. Open your Word document.
  2. Click on the Design tab in the ribbon.
  3. In the Page Setup group, click on Page Borders.
  4. In the Borders and Shading dialog box, select a Border Setting (e.g., Box, Shadow).
  5. Choose a Border Style (e.g., solid, dotted, dashed).
  6. Optionally, set the Apply to field to specific pages (e.g., First Page Only).
  7. Click OK to apply the border.

For Mac:

  1. Open your Word document.
  2. Click on the Format menu.
  3. Select Borders and Shading.
  4. In the Borders and Shading dialog box, select a Border Setting (e.g., Box, Shadow).
  5. Choose a Border Style (e.g., solid, dotted, dashed).
  6. Optionally, set the Apply to field to specific pages (e.g., First Page Only).
  7. Click OK to apply the border.

Text Border

  1. Select the text or image you want to border.
  2. Click on the Home tab in the ribbon.
  3. In the Paragraph group, click on Borders.
  4. In the Borders and Shading dialog box, select a Border Setting (e.g., Box, Shadow).
  5. Choose a Border Style (e.g., solid, dotted, dashed).
  6. Optionally, set the Apply to field to specific pages (e.g., First Page Only).
  7. Click OK to apply the border.

Additional Tips

  • To create a custom border, select the Custom option in the Borders and Shading dialog box. This allows you to set specific border widths, colors, and patterns for each side of the border.
  • To remove a border, select the content, go to the Borders and Shading dialog box, and select None from the Border Setting options.
  • Borders can be used to create tables by dividing the text into rows and columns. Select the text, go to the Borders and Shading dialog box, and choose a Table setting.
  • Borders can be applied to specific paragraphs or sections of the document by selecting the desired text and applying the border settings.
