Method 1: No Repeated Items (Combinations)

Formula:

Number of Combinations = n! / (n - r)! / r!

Explanation:

To understand this formula, let's break it down:

  • n! (n factorial): This represents the total number of permutations (arrangements) possible for n items.
  • (n - r)! (n-r factorial): This represents the number of permutations possible for the remaining items (n - r) that you are not choosing.
  • r! (r factorial): This represents the number of permutations possible within the group of r items that you are choosing.

By dividing n! by (n - r)! and r!, we eliminate the extra permutations that arise from the order of items and consider only the unique combinations.

Example:

Let's say you have 10 books on a bookshelf and want to display 6. Using the formula:

Number of Combinations = 10! / (10 - 6)! / 6! = 10! / 4! / 6! = 210

Therefore, there are 210 different groups of 6 books you can display from the 10 available.

Method 2: Repeated Items (Combinations with Repetition)

Formula:

Number of Combinations = (n + r - 1)! / (n - 1)! / r!

Explanation:

This formula is similar to the previous one, with the added consideration of repeated items.

  • (n + r - 1)!: This represents the total number of ways to place r items into n slots, even if some slots have multiple items.
  • (n - 1)!: This represents the number of ways to arrange the slots themselves, eliminating overcounting from the order of slots.
  • r!: This represents the number of permutations possible within the group of r items, as in Method 1.

Example:

Let's say you are ordering 5 items from a menu with 15 options. Using the formula:

Number of Combinations = (15 + 5 - 1)! / (15 - 1)! / 5! = 19! / 14! / 5! = 30,600

Therefore, there are 30,600 different orders of 5 items you can make from the 15 menu options, even if the items are repeated.
