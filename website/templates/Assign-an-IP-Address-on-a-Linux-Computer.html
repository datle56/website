Assign an IP Address to Your Linux Machine: A Step-by-Step Guide with Visual Aids


Unlock the Secrets of Static IP Configuration: A Comprehensive Guide

In the realm of networking, assigning a static IP address to your Linux machine can be likened to giving it a permanent postal address. It ensures your device has a stable and identifiable presence on your network, allowing for seamless communication and remote access. Whether you're an IT whiz or a networking novice, this step-by-step guide will empower you to effortlessly configure static IP addresses on your Linux device, paving the way for enhanced stability and control.


Method 1: Debian, Ubuntu, Linux Mint

1. Find Your Linux Version:

Open the Terminal application and type the following command:

lsb_release -a

This will display your Linux distribution name and version.

2. Open the Terminal App:

Click on the terminal icon on your desktop or press "Ctrl" + "Alt" + "T" to open the Terminal application.

3. Switch to the "Root" User:

Enter the following command and provide the root password when prompted:

sudo su

4. List Your Network Devices:

Use the following command to list all network devices:

ip addr

This will display a list of network interfaces, each with its name (e.g., "eth0" or "wifi0").

5. Select the Device You Want to Change:

Identify the device for which you want to change the IP address. If you want to change the IP address for your Ethernet connection, look for the device name starting with "eth". If you want to change the IP address for your Wi-Fi connection, look for the device name starting with "wifi".

6. Assign a New IP Address to the Device:

Use the following command to assign a new IP address to the selected device, replacing "eth0" with the actual device name and "192.168.1.100" with the desired IP address:

ifconfig eth0 192.168.1.100

7. Add a Default Gateway for Internet Access:

Specify the default gateway (usually the IP address of your router) to allow the device to access the Internet:

route add default gw 192.168.1.1

8. Add a DNS Server for DNS Resolution:

Add a DNS server (e.g., Google's public DNS server) to enable the device to resolve domain names:

echo "nameserver 8.8.8.8" >> /etc/resolv.conf

Method 2: Red Hat, CentOS, Fedora

1. Find Your Linux Version:

Open the Terminal application and type the following command:

cat /etc/os-release

This will display your Linux distribution name and version.

2. Open the Terminal App:

Click on the terminal icon on your desktop or press "Ctrl" + "Alt" + "T" to open the Terminal application.

3. Switch to the "Root" User:

Enter the following command and provide the root password when prompted:

sudo su

4. List Your Network Devices:

Use the following command to list all network devices:

nmcli dev list

This will display a list of network interfaces, each with its name (e.g., "eno12345678").

5. Switch to the Network Scripts Directory:

Navigate to the network scripts directory:

cd /etc/sysconfig/network-scripts

6. Display the Network Options for the Device You Want to Change:

Use the following command to display the network options for the selected device, replacing "eno12345678" with the actual device name:

cat ifcfg-eno12345678

7. Edit the Network Options:

Open the network options file for editing:

vi ifcfg-eno12345678

Make the following changes to the file:

  • BOOTPROTO: Change "dhcp" to "none" (static IP address)
  • IPV6 entries: Delete any lines related to IPv6 (e.g., "IPV6ADDR")
  • ONBOOT: Change "no" to "yes" (enable the device on boot)
  • IPADDR: Enter a new IP address, replacing "192.168.2.23" (e.g., 192.168.1.100)
  • PREFIX: Enter the prefix or netmask, replacing "24" or "255.255.255.0" (e.g., 24 or 255.255.255.0)
  • GATEWAY: Enter your gateway address (usually the IP address of your router), replacing "192.168.2.1" (e.g., 192.168.1.1)

8. Save and Exit the File:

Press "Esc" to enter command mode, then type ":wq" to save and exit.

Additional Notes:

  • You may need to restart the networking service for the changes to take effect:

    Debian, Ubuntu, Linux Mint: service networking restart

    Red Hat, CentOS, Fedora: systemctl restart network

  • If you encounter any issues, check the logs for errors:

    dmesg | tail


Conclusion:

Regardless of your Linux distribution, you can easily change the IP address of your network interface using the Terminal app. Whether you want to assign a static IP address for stability or configure DHCP for dynamic IP assignment, these methods provide simple and straightforward steps to effectively manage your network settings. By following these instructions, you can customize your network configuration to meet your specific requirements, ensuring seamless connectivity and optimal performance.
