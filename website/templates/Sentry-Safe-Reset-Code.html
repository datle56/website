How to Reset Safe Combinations

Obtaining Your Factory Code

The factory code is a crucial element in resetting your safe's combination. Here's how you can retrieve it:

  • Consult the Safe Manual: Often, the factory code is printed on the back or within the programming instructions included with your safe.
  • Lookup Online: Visit the website of the safe manufacturer, such as Sentry Safe, and search for your safe model. The factory code may be available online.
  • Request a Replacement: If you can't find the factory code, contact the safe manufacturer. They may provide a replacement for a fee.

Resetting Different Types of Safe Combinations

Fire Safe:

  1. Open the Door: Enter the factory code to unlock the door.
  2. Enable Programming Mode: Locate the "P" button and press it. Re-enter the factory code.
  3. Set New Code: Enter your desired 5-digit user code, which will replace the factory code.

Security Safe:

  1. Open the Door: Insert the keys or enter the factory code (1-7-5-0-0-#) to open the door.
  2. Access Battery Compartment: Locate the button inside the battery compartment and press it.
  3. Enter New Code: Type in your desired 2-8-digit user code followed by "#".

Depository Safe:

  1. Open the Door: Enter the master code (usually provided in the manual) to unlock the door.
  2. Enter Programming Mode: Press "#" followed by the master code and "#" again.
  3. Set New Code: Press "1-*", enter your new code, and press "#" twice.

Pistol Safe:

  1. Open the Door: Enter the factory code (1-2-3-4-1) to open the door.
  2. Enable Programming Mode: Press and hold the "1" key for 1-3 seconds.
  3. Enter New Code: After the keypad flashes purple, enter your desired 4-6-digit user code.
  4. Confirm Code: Re-enter the code when the keypad flashes purple again.

Additional Notes:

  • Always refer to your safe's user manual for specific instructions.
  • Write down your new code in a secure location to avoid forgetting it.
  • If you reset your combination and can't remember your new code, you may need to contact the safe manufacturer for assistance.
  • Regular maintenance of your safe, including battery replacement, is recommended to ensure optimal functionality.
