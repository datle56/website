Unlocking the Secrets of Schlage Locks: A Comprehensive Guide to Resets and Code Changes

Resetting Schlage Lock Models

Step-by-Step Instructions:

  1. Disconnect the Battery:

    Locate the battery compartment inside the lock and remove the battery. This will erase any stored memory and settings.

  2. Press the Schlage Button:

    Find the Schlage button, typically situated above the keypad, and hold it down for approximately 10 seconds. Observe the button carefully as it should start flashing or turn green.

  3. Reconnect the Battery:

    Within 10 seconds of pressing the Schlage button, quickly reconnect the battery to the lock. This will initiate the reset process.

  4. Enter the New Programming Code:

    If you wish to create a new programming code, press the number 3 followed by the new six-digit programming code twice. This will set the new code for your lock. If you prefer to use the default programming code, simply skip this step and proceed to programming the lock.

Setting a New Programming Code:

  1. Enter the Default Programming Code:

    Refer to the lock's manual or the sticker inside the lock to retrieve the default programming code. Enter this code on the keypad.

  2. Press the Schlage Button:

    After entering the default programming code, press the Schlage button above the keypad.

  3. Press Number 3:

    Enter the number 3, followed by the new six-digit programming code twice. This will set the new programming code for your lock.

  4. Programming Code Confirmation:

    The Schlage button will flash or beep to indicate that the programming code has been successfully changed.

Tips:

  • Keep the door ajar during the reset and programming process to ensure easy access to both sides of the lock.
  • If you forget your programming code, perform a factory reset by following the steps outlined in the lock's owner's manual.
  • For specific instructions or troubleshooting tips, consult the lock's owner's manual or the Schlage website.
