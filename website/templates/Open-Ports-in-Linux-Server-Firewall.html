Opening Ports on Linux Firewalls

Securing your Linux server involves configuring the firewall to restrict unauthorized access while allowing necessary services to function properly. This involves opening specific ports to enable incoming and outgoing connections. Here's a comprehensive guide to opening ports on various Linux firewalls:

Iptables

1. Login and Check Firewall Status:

  • Log in to your server via SSH or console.
  • Verify if the firewall is active using the command: bash service iptables status

2. List Current Firewall Rules:

  • To view the existing firewall rules, run: bash sudo iptables -L

3. Open a Port:

  • Open a specific port using the following syntax: bash sudo iptables -I [chain] -p [protocol] -m [protocol] --dport [port] -j ACCEPT
  • Replace [chain] with the appropriate chain (e.g., INPUT for incoming connections).
  • Specify the protocol (e.g., tcp or udp).
  • Use the --dport flag to specify the port number.

Example: Open port 22 (SSH) for incoming connections: bash sudo iptables -I INPUT -p tcp -m tcp --dport 22 -j ACCEPT

4. Save Changes:

  • After making changes, save them using: bash sudo service iptables save

Uncomplicated Firewall (UFW)

1. Login and Enable Firewall:

  • Log in to your server.
  • Enable the UFW firewall if it's not already running: bash sudo ufw enable

2. Open a Port:

  • Open a specific port using: bash sudo ufw allow [port number]

Example: Open port 80 (HTTP): bash sudo ufw allow 80

3. View Rules:

  • To view the current UFW rules, run: bash sudo ufw status verbose

4. Delete Rules:

  • To remove a rule, use the following command: bash sudo ufw delete [rule number]

Firewalld

1. Login and List Open Ports:

  • Log in to your server.
  • List the currently open ports with: bash firewall-cmd --list-ports

2. Open a Port:

  • To open a port, use the following syntax: bash firewall-cmd --zone=public --add-port=[port]/[protocol]

Example: Open port 25 (SMTP) for public access: bash firewall-cmd --zone=public --add-port=25/tcp

3. Make Changes Permanent:

  • To ensure the changes persist after a reboot, run: bash firewall-cmd --zone=public --permanent --add-port=[port]/[protocol]

ConfigServer Firewall (CSF)

1. Login and Edit Configuration:

  • Log in to your server as root.
  • Open the CSF configuration file in a text editor: bash vim csf.conf

2. Add Incoming and Outgoing Ports:

  • Add incoming ports to the TCP_IN list.
  • Add outgoing ports to the TCP_OUT list.

Example: Add incoming port 80 (HTTP) and outgoing port 443 (HTTPS): TCP_IN = "20,21,22,25,53,80,110,143,443,465,587" TCP_OUT = "20,21,22,25,53,80,110,143,443,465,587"

3. Save and Restart Firewall:

  • Save the changes to the configuration file.
  • Restart the CSF firewall: bash service csf restart

Advanced Policy Firewall (APF)

1. Login and Edit Configuration:

  • Log in to your server.
  • Open the APF configuration file in a text editor: bash sudo vim /etc/apf/conf.apf

2. Add Incoming and Outgoing Ports:

  • Add incoming ports to the IG_TCP_CPORTS list.
  • Add outgoing ports to the EG_TCP_CPORTS list.

Example: Add incoming port 80 (HTTP) and outgoing port 443 (HTTPS): IG_TCP_CPORTS="20,21,22,25,53,80,110,143,443,465,587" EG_TCP_CPORTS="20,21,22,25,53,80,110,143,443,465,587"

3. Save and Restart Firewall:

  • Save the changes to the configuration file.
  • Restart the APF firewall: bash service apf -r
