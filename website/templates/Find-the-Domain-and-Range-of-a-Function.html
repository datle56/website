Part 1: Finding the Domain

  • Identify the function type:

    • Quadratic function (ax² + bx + c): All real numbers
    • Fraction function: Exclude values that make the denominator zero
    • Root function: Exclude values that make the inside of the root negative

  • Write the domain with brackets and parentheses:

    • Brackets: Values included in the domain
    • Parentheses: Values excluded
