Prerequisites:

  • A computer with a terminal application (Command Prompt for Windows, Terminal for Mac)
  • Telnet (for both Windows and Mac)

Installation for Windows:

  1. Check Telnet Availability: Open Command Prompt by searching for it in the Start menu. Type telnet and press Enter. If you see a message stating "Telnet is not recognized," you will need to install it.

  2. Install Telnet: Open the Control Panel and navigate to "Programs and Features." Click on "Turn Windows features on or off." In the list, check the box next to "Telnet Client" and click OK. Restart your computer after installation.

Installation for Mac:

  1. Install Homebrew: If not already installed, open Terminal and type brew install homebrew. This package manager allows for easy installation of Telnet.

  2. Install Telnet: Once Homebrew is installed, type brew install telnet. Homebrew will handle the installation process.

Instructions:

  1. Launch Telnet: Open Command Prompt (Windows) or Terminal (Mac). Type telnet and press Enter.

  2. Enable Character Echoing: Type o (lowercase 'o') and press Enter. This activates the display of characters as they are typed.

  3. Connect to Server: Type towel.blinkenlights.nl and press Enter. This will establish a connection to the server hosting the ASCII Star Wars animation.

Tips:

  • The animation is approximately half the length of the original movie, providing a condensed version of the epic story.

  • The server hosting the animation may experience occasional downtime. If you encounter an error, please try again later.

  • Adjust the size of the terminal window for optimal viewing.
