Finding Your Windows Version

Method 1: Using the Windows Key and Run Command

  • Press the Windows key and the R key simultaneously to open the Run dialog box.
  • Type winver in the text box and press Enter.
  • A dialog box will appear, displaying your Windows version at the top.

Method 2: Through the Start Menu

  • Click the Start button in the lower-left corner of your screen.
  • In the search bar, type about and select the About your PC option.
  • Your Windows version will be listed under the Device specifications section.

Checking if Windows is 32-Bit or 64-Bit

Method 1: Using the Control Panel

  • Press the Windows key and the R key simultaneously to open the Run dialog box.
  • Type control panel in the text box and press Enter.
  • In the Control Panel window, click on System.
  • Your system type (32-bit or 64-bit) will be displayed next to System Type.

Method 2: Through the System Information App

  • Open the Start menu and type system information in the search bar.
  • Select the System Information app from the search results.
  • In the left pane, click on the System Summary item.
  • Scroll down to the System section and check the System Type entry.

Accessing Main System Information

  • Open the Start menu and type system information in the search bar.
  • Select the System Information app from the search results.
  • You will be presented with a wealth of detailed information about your system, organized into different tabs:
    • Hardware Resources: Provides information about your hardware devices, including processors, memory, and storage.
    • Components: Lists your installed hardware and software components, including drivers and services.
    • Software Environment: Provides details about your operating system, software settings, and environmental variables.
  • You can use these tabs to gather specific information about your Windows version, build number, system type, and other system components.
